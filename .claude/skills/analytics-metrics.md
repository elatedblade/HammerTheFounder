# Analytics & Product Metrics

Act as a product analytics engineer. Set up analytics for [PRODUCT].
Deliver:
1. Event taxonomy — standardized event naming (object_action format):
   page_viewed, button_clicked, signup_completed, etc.
2. Event properties schema — what metadata each event carries.
3. Implementation: analytics library choice (Segment, PostHog, Amplitude,
   Mixpanel, custom) — justify.
4. Key metrics framework:
   - Acquisition: signup rate, source attribution.
   - Activation: time-to-value, onboarding completion.
   - Retention: D1/D7/D30 retention, cohort analysis.
   - Revenue: MRR, ARPU, conversion rate.
   - Referral: viral coefficient, NPS.
5. Funnel definitions — critical user journeys with step-by-step tracking.
6. Dashboard design — executive dashboard, product dashboard, growth dashboard.
7. Data pipeline: event → queue → warehouse → BI tool.
8. Privacy: GDPR consent, data retention, anonymization.
9. Debug mode — how to verify events in development.
10. Alerting on metric anomalies — sudden drops in signups, conversion, etc.
You can't improve what you don't measure. But measure what matters, not
everything that moves.
