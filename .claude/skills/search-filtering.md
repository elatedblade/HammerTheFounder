# Search & Filtering

Act as a search engineer. Build production search for [PRODUCT].
Data: [what's being searched — products, users, articles, etc.].
Volume: [number of searchable documents].
Deliver:
1. Search engine choice: Elasticsearch / Typesense / Meilisearch /
   Algolia / PostgreSQL full-text — justify with trade-offs.
2. Index design — which fields, analyzers, tokenizers, synonym handling.
3. Search features: autocomplete, typo tolerance, faceted search,
   fuzzy matching, highlighting.
4. Filtering and sorting — facets, ranges, multi-select filters.
5. Relevance tuning — field boosting, custom scoring, A/B testing.
6. Index sync strategy — real-time vs. batch, event-driven reindexing.
7. Search analytics — what to track (queries, clicks, zero-results).
8. Performance: response time target < 100ms, pagination strategy.
9. Security: search result filtering based on user permissions.
10. Fallback: what happens when search service is down.
Search is the #1 feature users judge your product by. Invest accordingly.
